Cómo se obtiene cada iteración

Se parte de la condición inicial (x₀, y₀). En cada paso se calcula una nueva aproximación de y y se usa como punto de partida para el siguiente.

Euler explícito

Evalúa la pendiente en el punto actual y multiplica por el paso para estimar cuánto cambia y.

Runge–Kutta (RK4)

Combina la pendiente inicial, dos pendientes intermedias y una al final del paso.

Número de iteraciones

Con un paso positivo de 0,3 entre 0 y 1, se hacen cuatro pasos. Los tres primeros miden 0,3 y el último mide 0,1. Si das N directamente, la calculadora reparte el intervalo en N pasos. En los métodos, hn es el paso efectivo y lleva signo negativo al avanzar hacia un x menor.
